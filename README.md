# game-atelier

**게임 한 편이 한 사람이 되고, 그 게임의 조작이 그녀의 능력이 된다.**

게임 속 캐릭터가 아니라 게임 자체를 인격으로 만든 수집형 카드 게임. 장르·시대·대표 색·상징 소품이 겉모습이 되고,
핵심 조작이 결투의 능력이 된다. 세 폼(타이틀·중반·엔딩)은 플레이의 흐름, 개방은 그 폼의 명장면이다.

- 화면: [첫 화면](index.html) · [프롬프트](prompt.html) — GitHub Pages 로 연다. 서가·결투는 차례로 붙는다
- 기획: [docs/GAME_CONCEPT.md](docs/GAME_CONCEPT.md)
- 게임 설계표: [data/game-design.json](data/game-design.json) — `python3 tools/game-design.py check`
- 사실 자료: [tools/fetch-games.py](tools/fetch-games.py) — Wikidata(키 없음)
- 그림 규칙: [IMAGE_RULES.md](IMAGE_RULES.md) · 작업 지침: [AGENTS.md](AGENTS.md) · 가져온 것: [docs/PORT_NOTES.md](docs/PORT_NOTES.md)
- 그림은 이 저장소에 두지 않는다 — [game-atelier-img](https://github.com/polos0117/game-atelier-img)

뼈대는 book-atelier 에서 가져왔다. 게임 속 캐릭터·로고·타이틀 글자·UI 는 그리지 않는다. 비상업 팬작업이다.
